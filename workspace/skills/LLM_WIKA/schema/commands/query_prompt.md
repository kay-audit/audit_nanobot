# Команда query

```bash
python3.12 -m wiki_agent query "<вопрос пользователя>"
```

Проверить локальный выбор файлов без API:

```bash
python3.12 -m wiki_agent query --dry-run "<вопрос пользователя>"
```

Контроллер читает правила и индекс, выбирает релевантные страницы и передаёт
GigaChat только ограниченный контекст. Query ничего не записывает.
